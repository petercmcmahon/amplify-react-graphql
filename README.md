# AI/Tech News-Sentiment Backtesting Framework

> **Research tool only.** This app simulates a "buy AI/tech stocks on positive news
> sentiment" strategy against **historical** prices and headlines. It never places
> real trades, never connects to a brokerage account, and holds no brokerage
> credentials anywhere in the codebase. Backtest results are not investment advice,
> and historical performance is not indicative of future results. Sentiment scores
> are generated by an LLM and are heuristic — treat them as a way to explore a
> strategy's *shape*, not as a precision trading signal.

## What this is

A React + AWS Amplify (Gen 2) web app for backtesting a simple event-driven equity
strategy:

1. Pick tickers from a preset AI/tech watchlist (NVDA, MSFT, GOOGL, META, AMD,
   PLTR, SMCI, AMZN) or add your own.
2. Pick a historical date range and strategy parameters (sentiment/relevance
   thresholds, position size, holding period, stop-loss/take-profit).
3. The backend fetches historical prices (`yahoo-finance2`, falling back to
   Stooq), ingests historical headlines from a pluggable news source, scores
   each headline's sentiment/relevance with the Claude API (cached per headline
   so repeat runs are fast and free), and runs a deterministic backtest engine.
4. View the resulting equity curve, trade log, and performance metrics
   (total return, Sharpe ratio, max drawdown, win rate).

## Architecture

- **`amplify/data/resource.ts`** — Amplify Data (AppSync + DynamoDB) schema:
  `Ticker`, `Headline` (with a cached Claude sentiment/relevance score, keyed by
  content hash), `BacktestConfig`, `BacktestResult`.
- **`amplify/functions/run-backtest`** — the only deployed Lambda. It's a GraphQL
  custom mutation handler (`runBacktest`) that orchestrates everything else
  in-process (as plain library calls, not separate Lambda invocations):
  - **`../fetch-prices/priceSources`** — historical OHLCV via `yahoo-finance2`,
    with a Stooq CSV fallback.
  - **`../ingest-headlines`** — a pluggable `NewsSourceAdapter` interface with
    three implementations:
    - `seed-csv` (default): a small, offline, hand-curated set of real AI/tech
      headlines (Oct 2022–Jul 2023) — paraphrased, not scraped, no source URLs.
      Exists to make the demo flow deterministic without any external API.
    - `gdelt`: free, keyless historical news search via the GDELT Project (real
      research use, coverage back to 2015+).
    - `user-upload`: bring your own headline CSV (`ticker,text,url,publishedAt`)
      via the `USER_HEADLINES_CSV` environment variable.
  - **`../score-sentiment`** — batches unscored headlines to the Claude API
    (forced structured tool output) and caches the result per headline hash so
    re-running a backtest over the same range is nearly free.
  - **`engine/engine.ts` + `engine/metrics.ts`** — the pure, dependency-free
    backtest simulation, then writes a `BacktestResult`.
- **`src/`** — the React frontend: a config form and a results view (equity
  curve chart, trade log, metric tiles), talking to the backend only through the
  Amplify Data GraphQL API.

## Guardrails (structural, not just policy)

- No brokerage SDKs or credentials anywhere in the dependency tree.
- All "capital", "positions", and "P&L" are simulation-only values in DynamoDB —
  nothing here connects to a real bank or brokerage account.
- Purely historical simulation — there is no live/forward-trading mode and no
  "live mode" toggle on `BacktestConfig`.
- The disclaimer banner above is rendered on every page of the app.

## Getting started

```bash
npm install
npx ampx sandbox secret set ANTHROPIC_API_KEY   # your Anthropic API key
npx ampx sandbox                                 # deploys the backend, generates amplify_outputs.json
npm run dev                                      # in a second terminal
```

Then open the app, pick tickers + a date range that falls within the seed CSV's
covered window (Oct 2022–Jul 2023) with news source = "Seed demo dataset", and
run a backtest.

## Testing

```bash
npm test        # vitest — unit tests for the backtest engine, metrics, and adapters
npm run build   # type-check + production build of the frontend
```

The backtest engine and metrics module are pure functions with no AWS/network
dependencies, so their tests run instantly and deterministically. The Lambda
handlers (`fetch-prices`, `ingest-headlines`, `score-sentiment`, `run-backtest`)
require a deployed sandbox (`npx ampx sandbox`) to exercise end-to-end.
